## 📌 Project Overview

This project focuses on data cleaning, exploratory analysis, and interactive dashboard development in Microsoft Excel[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span). Using the Global Superstore dataset, the goal is to evaluate key business metrics, identify growth opportunities, and track regional sales efficiency[span_3](start_span)[span_3](end_span).

---

## 🔑 Key Metrics (KPIs)

- **Total Sales / Revenue:** $12.64M[span_4](start_span)[span_4](end_span)
- **Total Profit:** $1.47M[span_5](start_span)[span_5](end_span)
- **Profit Margin:** ~11.6%[span_6](start_span)[span_6](end_span)
- **Average Shipping Cost:** $26.48[span_7](start_span)[span_7](end_span)

## 📈 Visualizations & Features

1. **Category Performance:** Tracks total sales and order volume across Furniture, Office Supplies, and Technology[span_8](start_span)[span_8](end_span).
2. **Yearly Sales Trend:** Analyzes year-over-year revenue expansion from 2012 through 2015[span_9](start_span)[span_9](end_span).
3. **Market & Regional Breakdown:** Comparative revenue tracking across global regions (APAC, LATAM, USCA, EMEA, Africa)[span_10](start_span)[span_10](end_span).
4. **Sub-Category Profitability:** Drill-down into individual product lines to identify high-margin vs. loss-making products[span_11](start_span)[span_11](end_span).
5. **Dynamic Filtering:** Connected slicers for Category, Market, and Sub-Category enabling instant data slicing across all charts[span_12](start_span)[span_12](end_span).

## 🛠️ Tools & Concepts Applied

- **Excel Functions & Cleaning:** Data standardization, handling missing values, standard aggregation (`SUM`, `AVERAGE`, `COUNT`)[span_13](start_span)[span_13](end_span).
- **Pivot Tables & Calculated Fields:** Metric aggregation, percentage distributions, and summary views[span_14](start_span)[span_14](end_span).
- **Interactive UI:** Pivot Charts, Slicer connections, and executive card design[span_15](start_span)[span_15](end_span).
